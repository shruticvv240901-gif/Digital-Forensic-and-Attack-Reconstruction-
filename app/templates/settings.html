📖 How to Configure Splunk Connection

All settings are stored in the .env file in your project root. To connect your live Splunk Enterprise instance:

  1. Open the .env file in VS Code or any text editor.
  2. Set your Splunk administrative credentials: 
    SPLUNK_HOST=localhost
SPLUNK_MANAGEMENT_PORT=8089
SPLUNK_USERNAME=your_splunk_username
SPLUNK_PASSWORD=your_splunk_password
    Note: Port 8089 is the default Splunk management port for REST API calls (not the web port 8000).
  3. When you are ready to switch from demo data to real Splunk data, set: 
    DEMO_MODE=False
  4. Restart the Flask application and click Test Splunk Connection on the Dashboard.
